# Fiverr Websites

Professional, modern, and responsive website templates built for Fiverr clients.

## Purpose
This repository contains clean, reusable website templates that you can customize and deliver to Fiverr clients. All templates are:

- Fully responsive (mobile + tablet + desktop)
- Modern and professional design
- Easy to customize
- Fast loading
- Built with clean HTML, CSS (Tailwind), and JavaScript

## Repository Structure

```
fiverr-websites/
├── templates/                  # Individual website templates
│   ├── 01-business-landing/    # Company / Business landing page
│   ├── 02-portfolio/           # Personal or freelancers portfolio
│   └── 03-service-website/     # Service-based business website
├── shared/                     # Shared assets and components
│   ├── css/
│   ├── js/
│   └── images/
└── docs/                       # Guides and notes
```

## How to Use
1. Choose a template from the `templates/` folder
2. Customize the content, colors, and images
3. Test it on different screen sizes
4. Deploy (GitHub Pages or any host)
5. Deliver to your Fiverr client

## Getting Started
Each template folder contains its own `index.html` and assets so you can open and edit them independently.
