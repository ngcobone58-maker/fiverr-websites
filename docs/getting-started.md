# Getting Started

## How to work with these templates

1. Open any template folder (e.g. `templates/01-business-landing/`)
2. Open `index.html` in your code editor
3. Use GitHub Copilot or ask me for help to improve the design
4. Replace placeholder text and images with real content
5. Preview the page in your browser

## Recommended Tools
- VS Code + GitHub Copilot
- Live Server extension (for instant preview)
- Tailwind CSS (already included via CDN in the starters)
